## Техническое задание
1. Создать аннотацию (можно назвать её, например, AccessAllowed). 
2. обернуть в прокси класс OfficePrinter: при вызове методов на прокси-объекте сначала проверять наличие аннотации AccessAllowed и в случае её наличия выполнять проверку доступности оригинального метода.
   Если метод доступен, вызвать и вернуть его значение, иначе вывести в консоль сообщение «Access Denied!».
#### Требования к аннотации:
1. Должна иметь boolean-параметр для обозначения признака доступа к методу (true — доступ есть, false — метод недоступен для вызова).
    Значение параметра по умолчанию — true, то есть по дефолту метод считается доступным.
2. Аннотация должна быть применима только к методам и доступна в runtime для обработки инструментами Java Reflection API
3. Поставить эту аннотацию над всеми методами интерфейса Printer, при этом методы on() и print(String document) должны быть доступны,
 а методы printSecret(String secretDocument) и off() — закрыты от использования.
